## 与设计的偏差（均已写回设计 §3.5 / §6）
1. **影子不是 `--dry-run`**：`cycle.sh --shadow` 把池/best/黑名单重定向到 `.shadow/`，rank 正常写入，
   这样粘性在任者与淘汰历史真实演进；只有 audit 样本进入共享的 `vless_history.tsv`。
2. **规则 1 的阈值只取已证明（n_eff≥3）IP；溢出裁剪不得触及前 POOL_TARGET 名**。首轮影子（18:09，238 IP）
   把 52 个 master 淘汰了 42 个：169 个只有 2 个样本的试用 IP 把"第 60 名 lcb"抬到 0.845 → 26 个 master
   被判 unworthy；剩余超限按 ucb 裁"已证明"的 → 16 个优质 master（含 7 天回放 Top3 的 104.21.82.29）被当 overflow。
   修正后重算：237 保留、52 个 master 全部保留、Top3 不变。（溢出裁剪的最终形态见下文"模型定稿"规则 4。）
3. **切换时采用影子池**（`migrate.sh`）：补入影子期新晋升的 master，影子黑名单并入 `.screen_blacklist.tsv`。
4. rank.py 自动识别系统性失败轮（最新桶失败率 ≥50% 且样本 ≥5）升级 guard；PARTIAL 带延迟不算不可达。

## 2026-10-15/16 切换后 24h 复盘与模型定稿

切换后首日的生产数据暴露出迁移自 score.py 的估计量不适合"置信驱动"的淘汰，以及一个被全天等权掩盖的事实（晚高峰才是有区分度的时段）。本节是复盘结论与最终模型；中间的逐项修补不再保留。

### 观察到的事实
- 切换后 131 次剔除中约 **70 次（53%）属于误判**：中位数 49–52ms，p90 被最近 1–2 个 ~300ms 尖峰拉起（24h 半衰期下近期样本权重≈1，n≈5 时加权 p90 就是最大值）；另有 6 次是 4–5 个样本里 1 次抖动触发失败率折扣。它们的 u 从 0.9 跌到 0.1，固定的 K/√n 半宽罩不住。
- 真正该退出的 IP 画像一致：**中位数 51ms 但 20–30% 的样本在 ~300ms 或失败**，且这些坏样本集中在晚高峰。
- 按小时统计 7 天数据：晚高峰（20–00 点）失败率 6–10%、同轮 IP 间 IQR 80–110ms；其余时段 1–2% / 4–19ms；共同基线只从 49 涨到 56ms。**晚高峰不是噪声，是唯一有区分度的时段**；全天等权时 17/151 个池内 IP 的晚高峰问题（p90 >150ms）在全天 p90（<80ms）里不可见。
- 06:03 发生了第一次自然换血：两个在任者连续 14 个样本从 47 涨到 68ms，挑战者同时段稳定 48ms，4 小时后 lcb 差距越过滞回。换血本身正确，但触发它的是凌晨 02–04 点的退化——按用户体验这段时间权重应该最低。
- 池内 93/110 个 IP 在同一 /16；发布集跨 3 个 /16 纯属运气。
- 挑战者槽由 ucb 排序，新 IP 的宽区间 ucb 天然最高；快筛恢复后每轮 20 个新 IP 会把攒到 4–5 个样本的候选挤回 reserve。

### 最终模型（设计文档 §3.2–3.7 已按此重写）
1. **逐样本效用**：s = f(去共因 TTFB)，失败 = 0；权重 = 时效衰减 × 时段相关性（晚高峰 20–23,0 点 ×3）。mu/σ̂ 为加权均值/标准差；n_eff = min(Σ时效, Kish)，时段权重不虚增证据。
2. **方差感知区间**：lcb/ucb = mu ∓ z·√(σ̂²+σ0²)/√n_eff（z=1，σ0=0.15）。稳定 IP 的区间与原 K=0.15 等价；双峰 IP 自动宽一倍以上——丢 core/发布位，但不被判"确定更差"。这一条同时消灭了"p90 在小样本下是最大值"和"失败率点估计"两个问题，不需要任何单独修正。
3. **淘汰**：规则 1 需 n_eff ≥ 8（剔除比 core 资格要更多证据）；规则 2 失败率 Wilson 下界 > 30%；规则 3 连续不可达；**规则 4** 池 > POOL_MAX−20 时在"已表征且不在前 60 名"里按 ucb 裁最差者，每轮 ≤ 20——规则 1 是相对规则，新模型诚实地承认"100 个 mu≈0.8 的双峰 IP 互相证明不了更差"，没有阀门池会满、快筛停、系统冻结。不裁未表征的、不裁前 60 名。POOL_MAX 90→150。
4. **发布**：资格增加"近 24h 晚高峰样本 ≥3"（慢轮 20/22/00 正好 3 个，新 IP 必须扛过一个完整晚高峰）；发布集同 /16 ≤2，仅滞回内有跨段合格者时替换；优先级 合格性 > 质量 > 多样性 > 粘性。
5. **挑战者分槽**：探索槽（n_eff<3）5 + 晋升槽（n_eff≥3）5，一侧不足另一侧补齐。
6. **配置**：删除 RANK_K、VLESS_SOFT_MAX_FAIL；新增 RANK_Z、RANK_SIGMA0、RANK_PEAK_HOURS、RANK_PEAK_WEIGHT、RANK_PEAK_MIN_SAMPLES；PROBATION_PEAK_HOURS 改名 SCREEN_PEAK_HOURS（只用于快筛平峰判断，与排名的晚高峰是两个概念）。
